# Contributing to FileDroid

Thanks for taking the time to contribute. Here's how to get started.

## Getting Started

1. Fork the repo and create a branch from `main`
2. Make your changes — keep commits focused and descriptive
3. Open a pull request with a clear description of what you changed and why

For large changes, please open an issue first so we can discuss the approach before you invest time in it.

## Code Style

- Kotlin only
- Follow the existing project structure (`ui/`, `data/`, `remote/`, etc.)
- ViewModels own state, screens are stateless composables
- No hardcoded strings in UI — use descriptive labels

## Reporting Bugs

Open an issue and include:
- Android version and device
- Steps to reproduce
- What you expected vs. what happened
- Logcat output if available
